## 🌟 Overview

A luxury web application concept engineered for **PAVITHRAM CATERERS AND WEDDING PLANNERS**, a premier South Indian hospitality brand with a 30-year legacy hailing from the sacred culinary capital of **Kumbakonam**.

Inspired by the editorial elegance, rich hospitality layout, and high-impact visual standards of [Madhampatty Groups](https://madhampattygroups.com/), this website positions Pavithram as an elite turnkey wedding planner and culinary artisan.

## 🏛️ Key Features & Architecture

1. **Dual-Capability Value Proposition:**
   - **Speciality Catering:** Authentic Kumbakonam Elai Saapadu, live tawa counters, peaberry degree filter coffee, luxury buffets, and Sattvic pure vegetarian dining.
   - **Complete Wedding Arrangements:** Sacred Vedic ritual samangal, handcrafted Seer Bakshanam (Kai Murukku & cones), mandapam floral decor, Oonjal swing artistry, Janavasam vehicle styling, Flower Pallaku, Nadaswaram troupe, and silk-saree hostesses.

2. **Dedicated Wedding Arrangements Section (`#arrangements`):**
   - Four interactive category showcases with checklists:
     - Sacred Vedic Rituals & Samangal
     - Artisanal Seer Bakshanam
     - Mandapam, Stage & Floral Artistry
     - Hospitality, Live Stalls & Execution

3. **Interactive Enquiry & Consultation Form (`#enquiry`):**
   - Service scope selection (Turnkey Wedding, Catering Only, Decor Only, Seer Bulk Orders).
   - Multi-select interactive checkboxes for specific wedding arrangements.
   - Direct WhatsApp integration formatting a complete booking brief sent to verified business number `+91 95000 20547`.

4. **Lumer Labs Watermark & Safeguards:**
   - Persistent top notification banner.
   - 40% opacity full-webpage diagonal repeating watermark with `pointer-events-none`.
   - Floating badge and footer pitch disclaimer.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Gv-001251/Catering-mock-Webpage.git
cd Catering-mock-Webpage

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
